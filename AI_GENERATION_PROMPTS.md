## 📋 USAGE GUIDE

### For Image Generation:
1. Copy the prompt
2. Use `ai add:generate_image`
3. Select model: **nano_banana_pro** (recommended for quality)
4. Set dimensions as specified
5. Adjust opacity in design (20-25% for backgrounds)

### For Video Generation:
1. Copy the video prompt
2. Use `ai add:generate_video`
3. Select model: **seedance_2_0** (cinematic) or **kling3_0** (motion)
4. Duration: 15 seconds for projects, 3 seconds for transitions
5. Format: MP4 H.264, muted by default

### For Social Banners:
1. Use `design skill → banner-design` sub-skill
2. Copy the design brief
3. Or use `ai add:generate_image` with dimensions
4. Export in platform-specific format (PNG/JPG)

## 💡 TIPS FOR BEST RESULTS

1. **Be specific with dimensions** - Always include 1920x1080, 1920x600, etc.
2. **Mention "dark background"** - Critical for consistency with portfolio aesthetic
3. **Use color names consistently** - Say "orange" and "blue" rather than hex codes
4. **Request 4K/8K** - For high-quality final assets
5. **Add "professional"** - Ensures polished, not amateur, results
6. **Specify duration** - For videos (15 seconds, 3 seconds, etc.)
7. **Request loops** - For transition videos and animations
